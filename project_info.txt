             SMARTEXP: SMART EXPENSE TRACKER - PROJECT OVERVIEW
========================================================================

1. WHAT IS SMARTEXP?
--------------------
SmartExp is a modern, fintech-style web application designed for personal 
finance management. It helps users track their daily spending, set monthly 
budgets, and visualize their financial health through interactive charts 
and automated reports.

2. CORE FEATURES
----------------
- REAL-TIME TRACKING: Add expenses with titles, amounts, categories, and 
  payment methods.
- BUDGETING ENGINE: Set monthly limits for specific categories. Progress 
  bars turn red as you approach your limit.
- SMART ANALYTICS: See your average daily spend, predicted monthly total, 
  and top spending categories.
- PROFESSIONAL REPORTS: Export your transaction history as professional 
  PDFs or CSV files.
- PREMIUM UI: A "Glassmorphism" design that feels like a modern SaaS 
  product, with full support for Dark Mode.

3. FOR THE NON-TECHNICAL CLIENT (HOW TO EXPLAIN)
------------------------------------------------
"Imagine having a personal accountant in your pocket. SmartExp is a website 
where you just type in what you spend. Instead of looking at a boring list 
of numbers, it turns those numbers into beautiful charts so you can see 
EXACTLY where your money is going. It even warns you if you're spending too 
much on things like 'Dining Out' before you run out of money for the month."

4. Q&A (FREQUENTLY ASKED QUESTIONS)
-----------------------------------
Q: How secure is my data?
A: The system uses industry-standard authentication. Each user has their 
   own private database space, and records are encrypted at rest.

Q: Can I use this on my phone?
A: Yes, the design is "Responsive," meaning it automatically shrinks and 
   adjusts to look like a mobile app when opened on a phone.

Q: Can I change the currency?
A: Yes, there is a dedicated Settings page where you can switch between 
   Rupees (₹), Dollars ($), and other symbols.

Q: Is there any manual calculation required?
A: None at all. The system handles all the math, percentages, and 
   projections automatically in real-time.

5. THE TECHNOLOGY (WHAT'S UNDER THE HOOD?)
------------------------------------------
- FRONTEND (What you see): Built using HTML5 and Tailwind CSS for 
  a modern, responsive look. We used JavaScript and Chart.js to 
  create the interactive graphs and animations.
- BACKEND (The brain): Powered by Python and the Django Framework. 
  This handles the security, user accounts, and all the complex 
  financial logic behind the scenes.
- DATA STORAGE (The memory): Your data is stored in a secure 
  Relational Database. Currently, it uses SQLite for development, 
  which is highly efficient and keeps all your records organized 
  in one place.

Q: How is the database connected to the project?
A: The connection is handled through Django's Object-Relational 
   Mapping (ORM) system and the internal configuration in 
   settings.py:
   1. AUTOMATED MIGRATIONS: Instead of manual SQL scripts (JDBC 
      style), we use Django's Migration engine. It scans our 
      Python models and generates the database schema automatically.
   2. SQLITE ENGINE: The database is 'file-based' (db.sqlite3). 
      The backend connects to this file directly via a built-in 
      driver, so no external server or manual login (username/
      password) is required for development.
   3. SETTINGS CONFIG: The connection is established in the 
      DATABASES dictionary within the project settings, pointing 
      directly to the database file path.

6. DATA FLOW: FROM UI TO DATABASE (A TO Z)
------------------------------------------
Here is exactly how a single expense (like buying coffee) gets saved:

A. THE FORM (Frontend): The user enters "Coffee" and "₹150" into the 
   web form. When they click 'Save', the browser packages this data 
   into an "HTTP POST Request."

B. THE ROUTE (URLs): The project's URL system sees the request and 
   sends it to the specific 'View' responsible for adding expenses.

C. THE BRAIN (Views): The Python code in the View grabs the data from 
    the request. It checks if the user is logged in and if the 
   amount is a valid number.

D. THE TRANSLATOR (ORM): Instead of writing SQL code manually, the 
   View tells the 'Expense Model' to save. The Django ORM translates 
   our Python command: 
   `Expense.objects.create(title="Coffee", amount=150)` 
   into a SQL command: 
   `INSERT INTO expenses_expense (title, amount) VALUES ('Coffee', 150)`

E. THE STORAGE (Database): The built-in SQLite driver takes that SQL 
   command and writes it permanently into the 'db.sqlite3' file on 
   the hard drive.

F. THE FEEDBACK: Once saved, the database sends a "Success" signal 
   back to the view, which then redirects the user to the list page 
   with a "Success Message."
